## 최고 Jev

최고 Jev는 독립적 인 커뮤니티 기반 카탈로그입니다. **945 오픈 소스 프로젝트** 내장형 [뚱 베어](https://typesafe.ai/)TypeSafe AI 시스템 소프트웨어 내부 결정을위한 하나의 모델. TypeSafe AI에 의해 제휴 또는 승인되지 않습니다.

> **이 카탈로그는 유용합니까?**
>
> 모든 항목은 콘크리트 결정 Jev가 만들고 가장 강력한 공공 증거에 대한 링크를 식별합니다. 따라서 실제 구현을 평가 할 수 있으므로 프로젝트가 주장하지 않습니다.

## Jev 소개

Jev는 **주요 특징** 플러스 하나 이상의 타입 **이름 *** 그리고 코드를 직접 사용할 수 있는 구조화된 답변을 반환합니다. 그것은 prose를 생성하지 않습니다.

/ 특전 / 이용 / 반품 /
|---|---|---|
· [이름 * ₢ 킹](https://docs.typesafe.ai/primitives/choice) · 알려진 세트에서 하나의 옵션을 선택 / 선택된 옵션, 확률, 신뢰 /
· [`Score``를](https://docs.typesafe.ai/primitives/score) · 주문형 루비에 뭔가를 배치 / 점수, 레벨 확률, 신뢰 /
· [₢ 킹](https://docs.typesafe.ai/primitives/noul) / 성명이 참인지 여부 / 0에서 1까지의 확률 /

하나의 요청에서 같은 상태를 공유하고 독립적으로 평가됩니다. 복잡한 결정은 좁은 질문과 일반 코드로 구성해야합니다. Authorization, arithmetic, 임계값, 부작용 및 fallback 동작은 코드에 남아 있어야 합니다.

Jev에 새로운? TypeSafe의 공식 시작 [제품정보](https://docs.typesafe.ai/introduction), 다음 계속 [이름 *](https://docs.typesafe.ai/primitives)· [관련 기사](https://docs.typesafe.ai/confidence)· [패턴](https://docs.typesafe.ai/patterns)·

## 왜 이 목록이 존재할까요?

대부분의 감독은 Jev를 사용합니다. 이 목록은 또한 기록합니다:

- - - **어떤 Jev 결정** — 프로젝트 내부의 정확한 판단.
- - - **혐기성** — state → 질문 → 대답 → 코드 동작.
- - - **전화 사이트 증거** — 하나가 공개될 때 구현에 대한 링크.
- - - **Reproduction 상태** — runbook이 존재하고 독립적 인 검토자가 ran 그것인지 여부.
- - - **미터 검증** — 공식, 저자 허가, 또는 독립적으로 재제작.
- - - **제품 정보** — 마지막 인간 검토 날짜 및 현재 프로젝트 상태.
- - - **재사용 가능한 패턴** — 다른 제품에 전송 하는 아키텍처.

우리는 검사 및 사용성, 목록 크기 또는 GitHub 별을 최적화합니다.

## 자주 묻는 질문

```text
프로젝트 — Jev가 결정하는 것.
Primitive : 선택 · 패턴 : 유형 도구 파견
Evidence : 사이트 확인 · 유지 보수 실행 책 · 미터 승인
```

검증 라벨은 별도의 사실을 설명합니다. 그들은 점수 또는 순위가 아닙니다.

/ 상표 / 의미 /
|---|---|
· **회사연혁** · 저장소는 공공이며 README는 콘크리트 Jev 워크플로우를 설명합니다. ·
· **자주 묻는 질문** · Jev를 호출하고 그 대답을 소비하는 공개 코드를 유지. ·
· **데모 만** · 공개 데모는 행동을 보여줍니다, 그러나 검사 가능한 전화 사이트가 발견되지 않았습니다. ·
· **README 청구** · 업스트림 프로젝트는 Jev를 사용합니다. 전화 사이트는 확인되지 않았습니다. ·
· **회사 소개** · 업스트림 프로젝트는 설정 및 실행 지침을 제공합니다. ·
· **작성자 reproduced** · 자주 묻는 질문(FAQ) ·
· **Author-reported 메트릭** · 숫자는 프로젝트 저자에서 옵니다 그리고 자주적으로 재제작되지 않았습니다. ·

## 법적 고지

등록된 프로젝트는:

1. 명세 공개적으로 접근하고 인용할 수 있습니다.
2. Explicitly 사용 Jev, 공식 Jev 리소스를 제공, 또는 독립적 Jev-style 구현 문서.
3. 명세 한 문장에서 설명 할 수있는 구체적인 유형 결정.
4. 명세 가장 강력한 유효한 증거에 연결.
5. 명세 제출자의 프로젝트에 대한 관계를 닫습니다.

프로젝트는 **아니다.** 높은 GitHub 별이 필요합니다. Experimental 및 초기 작업은 상태와 증거가 정확하게 설명될 때 환영받습니다.

우리는 단지 Jev, 콘크리트 결정없이 링크 덤프, 접근 가능한 소스, 복사 된 문서 및 성능 주장과 같은 일반적인 AI 프로젝트를 제외합니다.
