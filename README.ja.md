## Awesome Jevについて

Awesome Jevは独立したコミュニティ維持されたカタログです **834 オープンソースプロジェクト** 組み込み [ジェヴ](https://typesafe.ai/)、タイプ安全AIのシステム ソフトウェア内部の決定を一式化するためのモデル。 TypeSafe AIに所属、または支持されることはありません。

> **このカタログは役に立ちますか?**
>
> すべてのエントリは、具体的な決定Jevを識別し、利用可能な最も強力なパブリック証拠へのリンクを構成します。そのため、プロジェクトクレームだけでなく、実際の実装を評価することができます。

## Jevとは

ジェフは、 **ステート** 1 つ以上のタイプ **お問い合わせ** コードが直接使用できる構造化された応答を返します。 プロスを生成しません。

/ 原始 / 利用 / 返品 /
|---|---|---|
お問い合わせ [チョイス ログイン](https://docs.typesafe.ai/primitives/choice) お問い合わせ 既知のセットから1つのオプションを選択 / 選択されたオプション、確率、自信 /
お問い合わせ [サインイン](https://docs.typesafe.ai/primitives/score) お問い合わせ オーダールックル / スコア・レベルの確率・自信 /
お問い合わせ [ヌール](https://docs.typesafe.ai/primitives/noul) / 声明が真実かどうかを推定 / 0 から 1 までの確率 /

1つの要求の質問は同じ状態を共有し、独立して評価されます。 複雑な決定は、狭い質問に分割し、通常のコードで構成する必要があります。 認可、算術、しきい値、副作用、およびフォールバックの動作は、コードに残る必要があります。

Jevに新しい? TypeSafeの公式アカウントでスタート [導入事例](https://docs.typesafe.ai/introduction)続いて、 [プリミティブ](https://docs.typesafe.ai/primitives), [コンプライアンス](https://docs.typesafe.ai/confidence)と [パターン](https://docs.typesafe.ai/patterns)お問い合わせ

## このリストが存在する理由

ほとんどのディレクトリは、プロジェクトがJevを使用することを伝えます。 このリストはレコードも記録します。

- - - **Jevが何を決めたのか** - プロジェクト内で行われた正確な判断。
- - - **デシオン解剖学** — 状態 → 質問 → 回答 → コードアクション.
- - - **コールサイト証拠** — 公開時に実装へのリンク。
- - - **再生状態** — Runbookが存在し、独立した査読者がそれを実行しているかどうか。
- - - **メトリックの実績** — 正式、著者報告、または独自に再現。
- - - **フレッシュネス** — 最後の人間レビュー日と現在のプロジェクトステータス。
- - - **再使用可能なパターン** — 他の製品に転送するアーキテクチャ。

検査性と有用性を最適化し、サイズやGitHubの星をリストしません。

## 除外基準

リストされたプロジェクトは、次のものでなければなりません。

1。 一般にアクセス可能で、引用可能である。
2. Jev を明示的に使用し、公式 Jev リソースを提供したり、独立した Jev スタイルの実装を文書化したりします。
3。 ひとつの文章で記述できる具体的なタイプの決定を行います。
4。 最も強力な利用可能な証拠へのリンク。
5。 5。 提出者のプロジェクトとの関係を解除します。

プロジェクトは **お知らせ** ハイ GitHub の星が必要です。 現状と証拠が正確に記述されると実験的および初期段階の作業が歓迎されます。
